### ما هو Markdown؟

Markdown هي لغة ترميز خفيفة الوزن يمكنك استخدامها لتنسيق مستندات النص العادي.  
اكتب مستندات لمشاريعك على GitHub، وحرر ملف _README_ في ملفك الشخصي على GitHub، وما إلى ذلك. ستجد كل ما تحتاجه هنا.

لنبدأ. ⤵️

## العناوين

هناك 6 أنواع من العناوين. يشير عدد رموز "#"، المتبوعة بالنص، إلى أهمية العنوان.

```
# العنوان 1
## العنوان 2
### العنوان 3
#### العنوان 4
##### العنوان 5
###### العنوان 6
```

# العنوان 1

## العنوان 2

### العنوان 3

#### العنوان 4

##### العنوان 5

###### العنوان 6

## التمييز

تعديل النص عملية بسيطة وسهلة للغاية. يمكنك جعل النص غامقًا أو مائلًا أو مشطوبًا.

```
باستخدام علامتي نجمة **يكون هذا النص غامقًا**.
استخدام شرطتين سفليتين __يعمل أيضًا__.
لنجعله *مائلًا الآن*.
لقد خمنت ذلك، _شرطة سفلية واحدة تكفي أيضًا_.
هل يمكننا الجمع **_بين الاثنين_؟** بالطبع.
ماذا لو أردت ~~شطب النص~~؟
```

باستخدام علامتي نجمة **هذا النص بخط عريض**.  
علامتا خط تحت **تفيان بالغرض أيضًا**.  
لنجعله _مائلاً الآن_.  
لقد خمنت ذلك، _علامة خط تحت واحدة تكفي أيضًا_.  
هل يمكننا الجمع بين **_كلا الأمرين_؟** بالطبع.  
ماذا لو أردت ~~شطب النص~~؟

## الكود

يمكنك إنشاء مقتطفات كود مضمنة أو ككتلة كاملة. يمكنك أيضًا تحديد لغة البرمجة التي تستخدمها في مقتطفك. كل ذلك باستخدام علامات الاقتباس المائلة.

````
    لقد أنشأت ملف `.env` في المجلد الجذر.
    علامات اقتباس مائلة داخل علامات اقتباس مائلة؟ `` `لا مشكلة.` ``

    ```
    {
 learning: "Markdown",
 showing: "مقتطف كود كتلة"
    }
    ```

 ```js
    const x = "مقتطف كود كتلة في JS";
    console.log(x);
    ```
````

لقد أنشأت ملف `.env` في المجلد الجذر.
علامات اقتباس مائلة داخل علامات اقتباس مائلة؟ `` `لا مشكلة.` ``

```
{
  learning: "Markdown",
  showing: "مقتطف كود في كتلة"
}
```

```js
const x = 'مقتطف كود في JS'؛
console.log(x);
```

## القوائم

### القائمة المرتبة

1. HTML
2. CSS
3. جافا سكريبت
4. React
7. أنا الآن مطور واجهة مستخدم 👨🏼‍🎨
```

1. HTML

3. جافا سكريبت
4. React
5. أنا الآن مطور واجهة مستخدم 👨🏼‍🎨

```
- Node.js
+ Express
* Nest.js
- أتعلم البرمجة الخلفية ⌛️
```

- Node.js

* Express

- Nest.js

* أتعلم البرمجة الخلفية ⌛️

```

   - React

## الجدول

طريقة رائعة لعرض البيانات بشكل منظم. استخدم الرمز "|" لفصل الأعمدة والرمز ":" لمحاذاة محتوى الصفوف.

```
| محاذاة إلى اليسار (افتراضي) | محاذاة إلى الوسط | محاذاة إلى اليمين |
| :------------------- | :----------: | ----------: |
| React.js | Node.js | MySQL |
| Next.js | Express | MongoDB     |
| Vue.js | Nest.js | Redis |
```

| محاذاة إلى اليسار (افتراضي) | محاذاة إلى الوسط | محاذاة إلى اليمين |
| :------------------- | :----------: | ----------: |
| React.js |   Node.js    | MySQL |
| Next.js |   Express    |     MongoDB |
| Vue.js |   Nest.js    | Redis |

## الانتقال إلى القسم

يقوم Astro (ومعظم برامج تحليل Markdown) بإنشاء معرّفات للعناوين تلقائيًا. وعادةً لا تحتاج إلى إنشاء علامات `<a name="...">` يدويًّا.

## الخط الأفقي

يمكنك استخدام العلامات النجمية أو الواصلات أو الخطوط السفلية (\*, -, \_) لإنشاء خط أفقي.  
القاعدة الوحيدة هي أنه يجب عليك تضمين ثلاثة أحرف على الأقل من الرمز.

```
الخط الأفقي الأول

***

الخط الثاني

-----

الخط الثالث

_________
```

## HTML

يمكنك أيضًا استخدام HTML الخام في ملف Markdown الخاص بك. في معظم الأحيان سيعمل ذلك بشكل جيد، ولكن في بعض الأحيان قد تواجه بعض الاختلافات التي لست معتادًا عليها عند العمل مع HTML القياسي. لن يعمل استخدام CSS.
